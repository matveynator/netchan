# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| v2 | Yes |
| v1 | No, archived |

Security fixes are released as new immutable semantic versions. Published tags
are never moved or reused.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/matveynator/netchan/security/advisories/new)
and include the affected version, a minimal reproduction, the expected impact,
and any suggested remediation.
